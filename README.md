# 📋 Sistema de Cadastro de Nomes

Projeto desenvolvido em Python com foco em praticar lógica de programação, manipulação de arquivos e interação com o usuário pelo terminal.

O sistema permite cadastrar, listar e remover nomes de forma simples, armazenando os dados automaticamente em um arquivo `.txt`.

---

## 🚀 Funcionalidades

✅ Cadastro de nomes  
✅ Verificação de nomes duplicados  
✅ Listagem em ordem alfabética  
✅ Remoção de nomes cadastrados  
✅ Salvamento automático em arquivo  
✅ Tratamento básico de erros  

---

## 🛠️ Tecnologias utilizadas

- Python 3
- Manipulação de arquivos `.txt`
- Estruturas condicionais
- Loops
- Funções

---

## 📂 Como funciona

Os nomes cadastrados são armazenados no arquivo:

```txt
nomes.txt
```

Assim, mesmo fechando o programa, os dados permanecem salvos.

---

## ▶️ Como executar

1. Instale o Python 3
2. Baixe o projeto
3. Execute o arquivo:

```bash
python main.py
```
